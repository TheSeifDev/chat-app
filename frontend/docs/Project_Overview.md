# Project Overview

## Purpose

This repository is a frontend scaffold for a chat application. It provides a mobile-first UI foundation, component primitives, and a simple auth flow implemented using Expo Router and React Native.

## Main features

- Splash screen and animated transitions
- File-based routing with Expo Router
- Auth screens (Welcome, Register, Login) — UI only
- Reusable components: `ScreenWrapper`, `Typo`, `Input`, `Button`, `BackButton`
- Centralized theme tokens for consistent styling

## Current state

- Frontend only — no backend or API integration
- Auth UI present but submission handlers are placeholders (no network calls or token handling)
- Well-structured UI layer suitable for further development
